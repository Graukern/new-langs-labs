# Лабораторные работы по новым языкам программирования

В репозитории собраны 20 небольших программ на 20 языках. Работы разделены
на пять тем. Для каждой программы есть свой README с требованиями и командой
запуска.

| Тема | Язык | Что делает программа |
|---|---|---|
| Многопоточность | Ada | Делит диапазон чисел между четырьмя задачами и считает общий результат |
| Многопоточность | D | Сравнивает последовательное и параллельное вычисление суммы квадратных корней |
| Многопоточность | Elixir | Параллельно считает квадраты чисел и собирает результаты |
| Многопоточность | F# | Четыре задачи считают простые числа в разных частях диапазона |
| Алгоритмы | Haskell | Сортирует массив алгоритмом сортировки слиянием |
| Алгоритмы | Julia | Рекурсивно считает количество островов в матрице |
| Алгоритмы | Kotlin | Рекурсивно находит максимальную глубину бинарного дерева |
| Алгоритмы | Standard ML | Решает задачу о количестве способов подняться по лестнице |
| Ввод-вывод | Groovy | Считает строки, слова и символы в текстовом файле |
| Ввод-вывод | Lua | Добавляет заметки в файл и выводит их с номерами |
| Ввод-вывод | Perl | Фильтрует строки журнала по уровню сообщений |
| Ввод-вывод | Ruby | Копирует файл с нумерацией строк и считает их количество |
| Клиент-сервер | Nim | Запускает TCP echo-сервер и возвращает сообщения клиенту |
| Клиент-сервер | Objective-C | Отправляет HTTP-запрос и печатает ответ сервера |
| Клиент-сервер | Rust | Обрабатывает TCP-подключения и вычисляет задачи клиентов |
| Клиент-сервер | Swift | Принимает сообщения через TCP и отвечает клиентам |
| Конвертация данных | Mojo | Переводит CSV-файл в Markdown-таблицу |
| Конвертация данных | Odin | Переводит конфигурацию из формата `ключ=значение` в JSON-подобный вид |
| Конвертация данных | Scala | Переводит CSV-файл в XML |
| Конвертация данных | Zig | Переводит блоки записей `ключ=значение` в CSV |
