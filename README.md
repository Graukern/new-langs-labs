## План на согласование

### 1.4. F# — сводка температур по метеостанциям

- **Входные данные.** Пути к двум или более текстовым файлам. Каждый файл
  содержит показания одной станции, по одной целой температуре в градусах
  Цельсия на строку.
- **Результат.** Для каждой станции программа выводит имя файла, количество
  показаний, минимальную, максимальную и среднюю температуру.
- **Основные требования.** Каждый файл читается и обрабатывается в отдельной
  задаче. Главный поток ждёт завершения задач и выводит сводки в порядке
  переданных файлов. Для пустого файла или неверного показания программа
  выводит сообщение с именем файла.

### 2.1. Haskell — раскрытие вложенных повторов команд

- **Входные данные.** Строка из команд `F`, `L` и `R`. Запись `N[...]`
  повторяет блок `N` раз, где `N` — положительное целое число. Внутри блока
  могут быть другие повторы.
- **Результат.** Программа выводит полную последовательность команд.
  Например, из `2[F3[LR]]` получается `FLRLRLRFLRLRLR`.
- **Основные требования.** Разбирать вложенные блоки рекурсивно, сохраняя
  порядок команд. При неизвестной команде, неверном числе повторов или
  несогласованных скобках выводить сообщение об ошибке.

### 3.1. Groovy — оглавление Markdown-файла

- **Входные данные.** Путь к Markdown-файлу в UTF-8 и путь к выходному
  текстовому файлу.
- **Результат.** Одна строка оглавления на каждый заголовок. В строке указаны
  номер строки исходного файла, уровень заголовка и его название. Например,
  для `## Запуск` на пятой строке программа записывает `5 — 2 — Запуск`.
- **Основные требования.** Читать файл построчно и сохранять порядок
  заголовков. Учитывать заголовки, начинающиеся с одного–шести символов `#`
  и пробела. Пропускать строки внутри блоков кода, ограниченных тройными
  обратными кавычками.

### 3.3. Perl — сравнение остатков товаров

- **Входные данные.** Пути к двум текстовым файлам с остатками до и после
  обновления. В каждой строке указаны артикул и целое неотрицательное
  количество через пробел. В каждом файле артикул встречается один раз.
- **Результат.** В консоли выводится отчёт о добавленных, удалённых и
  изменившихся позициях. Для изменившейся позиции показываются оба количества.
  Например, если `A101 5` стало `A101 8`, отчёт показывает `A101 — 5 → 8`.
- **Основные требования.** Сравнивать записи по артикулу независимо от порядка
  строк в файлах. Совпадающие позиции пропускать. В каждой группе отчёта
  выводить позиции в порядке артикулов.
