# Оглавление Markdown-файла на Groovy

Программа читает Markdown в UTF-8 и записывает оглавление в отдельный
текстовый файл. В каждой строке указаны номер строки, уровень и название
заголовка. Учитываются заголовки с `#` и пробелом. Строки внутри блоков
с обратными кавычками пропускаются.

## Запуск

```bash
groovy src/main.groovy sample/guide.md /tmp/outline.txt
cat /tmp/outline.txt
```
