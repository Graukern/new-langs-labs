# Сравнение остатков товаров на Perl

В каждом входном файле на строке указаны артикул и целое неотрицательное
количество через пробел. В отчёте выводятся добавленные, удалённые и
изменившиеся позиции. В каждой группе артикулы отсортированы.

## Запуск

```bash
perl src/main.pl sample/before.txt sample/after.txt
```

В примере добавлен `B202`, удалён `D404`, а остаток `A101` изменился с 5 на 8.
