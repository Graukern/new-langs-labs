# Преобразование PPM P3 в XPM на Odin

Программа читает текстовое изображение PPM P3 с максимальным значением канала
255. Она сохраняет размеры и цвета, составляет палитру и записывает пиксели
в XPM с кодами цветов одинаковой длины.

## Запуск

```bash
odin run src/main.odin -file -- sample/tiles.ppm /tmp/tiles.xpm
cat /tmp/tiles.xpm
```

В примере два цвета, красный и синий.
