# Конвертация записей в CSV на Zig

Программа читает файл с записями в формате `ключ=значение`. Каждое поле
записано на отдельной строке, записи разделены пустой строкой. Имена полей
первой записи становятся заголовком CSV, значения каждой записи — строкой CSV.

Пример входа (`sample/records.txt`):

```
name=Аня
age=20

name=Иван
age=21
```

Результат:

```
name,age
Аня,20
Иван,21
```

## Запуск

```bash
zig run src/main.zig -- sample/records.txt
```

Проверено на Zig 0.14.1.
