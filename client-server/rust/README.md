# TCP-сервер задач на Rust

Программа запускается как TCP-сервер и обрабатывает подключения в отдельных
потоках. Клиент отправляет число, а сервер возвращает его квадрат.

## Запуск

В первом терминале:

```bash
rustc src/main.rs -o server
./server server 127.0.0.1:9200
```

Во втором терминале:

```bash
./server client 127.0.0.1:9200 12
```
