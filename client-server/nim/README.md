# TCP-сервис медианы на Nim

Сервер хранит числа отдельно для каждого подключения. Команда `ADD <число>`
добавляет знаковое целое число и получает ответ `OK`. Команда `MEDIAN`
возвращает медиану или ошибку, если список пуст.

## Запуск

В первом терминале:

```bash
nim c -o:/tmp/median src/main.nim
/tmp/median server 127.0.0.1 9000
```

Во втором терминале:

```bash
/tmp/median client 127.0.0.1 9000 'ADD 7' 'ADD 2' MEDIAN
```

Ответы — `OK`, `OK` и `4.5`.
