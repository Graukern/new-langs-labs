# Echo-сервер на Nim

Программа работает как простой TCP echo-сервер или клиент. Сервер возвращает
клиенту полученное сообщение.

## Запуск

В первом терминале:

```bash
nim c -d:release -o:server src/main.nim
./server server 127.0.0.1 9000
```

Во втором терминале:

```bash
./server client 127.0.0.1 9000 "Привет от клиента"
```
