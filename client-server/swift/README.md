# Сервер сообщений на Swift

Программа работает как простой TCP-сервер. Клиент отправляет сообщение, а
сервер возвращает его с коротким подтверждением и продолжает ждать клиентов.

## Запуск

В первом терминале:

```bash
swiftc src/main.swift -o server
./server server 127.0.0.1 9300
```

Во втором терминале:

```bash
./server client 127.0.0.1 9300 "Привет от Swift"
```
