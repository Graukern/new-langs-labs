# Сравнение вычислений в D

Программа считает сумму квадратных корней чисел от 1 до N обычным циклом и
параллельно через `taskPool.reduce`, а потом показывает время обоих вариантов.
По умолчанию N = 50 000 000.

## Требования

- LDC;
- Ubuntu в WSL 2.

## Запуск

Из этой папки:

```bash
ldc2 -O3 -of=main src/main.d
./main
```

Можно передать верхнюю границу:

```bash
./main 100000000
```
