# Обработка строк в D

Программа запускает несколько задач и считает длину строк параллельно.
Результаты потом складываются в одном потоке.

## Требования

- LDC;
- Ubuntu в WSL 2.

## Запуск

Из этой папки:

```bash
ldc2 -of=main src/main.d
./main
```

Можно передать число строк:

```bash
./main 1000
```
