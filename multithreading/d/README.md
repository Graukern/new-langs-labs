# Сравнение вычислений в D

Программа считает сумму квадратов большого массива чисел обычным циклом и
через `taskPool`, а потом показывает время обоих вариантов.

## Требования

- LDC;
- Ubuntu в WSL 2.

## Запуск

Из этой папки:

```bash
ldc2 -O3 -of=main src/main.d
./main
```

Можно передать верхнюю границу:

```bash
./main 1000000
```
