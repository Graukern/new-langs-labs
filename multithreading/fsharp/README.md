# Параллельная обработка файлов в F#

Программа создаёт несколько задач и считает количество символов в переданных
файлах. Для примера без дополнительных файлов используются строки из аргументов
командной строки.

## Требования

- .NET SDK с поддержкой F#;
- Ubuntu в WSL 2.

## Запуск

Из этой папки:

```bash
dotnet fsi src/main.fsx
dotnet fsi src/main.fsx hello world
```
