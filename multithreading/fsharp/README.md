# Параллельная обработка значений в F#

Программа создаёт четыре задачи. Каждая считает простые числа в своей части
диапазона.

## Требования

- .NET SDK с поддержкой F#;
- Ubuntu в WSL 2.

## Запуск

Из этой папки:

```bash
dotnet fsi src/main.fsx
dotnet fsi src/main.fsx 200000
```

По умолчанию верхняя граница равна `200000`.
