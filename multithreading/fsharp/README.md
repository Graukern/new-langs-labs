# Сводка температур по метеостанциям на F#

В каждом входном файле указаны целые температуры одной станции, по одной на
строку. Программа обрабатывает каждый файл в отдельной задаче и выводит
количество измерений, минимум, максимум и среднее в порядке переданных файлов.

## Запуск

Из этой папки в WSL 2 с .NET SDK:

```bash
dotnet fsi src/main.fsx sample/north.txt sample/south.txt
```

Средние температуры в примере — −2.00 °C и 9.00 °C.
