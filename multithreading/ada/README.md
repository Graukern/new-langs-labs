# Параллельная проверка латинского квадрата в Ada

Программа проверяет, встречается ли каждое число от 1 до N ровно один раз
в каждой строке и каждом столбце. Одна задача Ada проверяет строки,
другая проверяет столбцы. Основная программа ждёт завершения обеих задач
и выводит общий результат.

В первой строке входного файла указывается положительный порядок квадрата N.
В следующих N строках должно быть по N целых чисел, разделённых пробелами.

## Требования

- Ubuntu в WSL 2;
- GNAT.

## Запуск

Из этой папки:

```bash
gnatmake -o main src/main.adb
./main sample/square.txt
```

Для этого примера программа выводит «Матрица является латинским квадратом.».
