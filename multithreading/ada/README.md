# Параллельная обработка диапазона в Ada

Программа делит диапазон чисел между четырьмя задачами Ada. Каждая задача
считает сумму квадратов для своей части диапазона. Частичные результаты
складываются в одном защищённом аккумуляторе.

## Требования

- Ubuntu в WSL 2;
- GNAT.

## Запуск

Из этой папки:

```bash
gnatmake -o main src/main.adb
./main
./main 10
```

По умолчанию верхняя граница равна `100`. Она должна быть не меньше `4`.
