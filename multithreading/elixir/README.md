# Конкурентный сбор результатов в Elixir

Программа запускает отдельный процесс Elixir для каждого числа. Процессы
считают квадраты чисел и отправляют результаты обратно главному процессу.

## Требования

- Elixir;
- Ubuntu в WSL 2.

## Запуск

Из этой папки:

```bash
elixir src/main.exs
elixir src/main.exs 10
```

По умолчанию обрабатываются числа от `1` до `10`.
