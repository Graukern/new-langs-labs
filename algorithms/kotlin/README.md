# LeetCode 104 на Kotlin

Решение задачи [104. Maximum Depth of Binary Tree](https://leetcode.com/problems/maximum-depth-of-binary-tree/).
Глубина бинарного дерева считается рекурсивно.

## Требования

- Kotlin/JVM;
- Ubuntu в WSL 2.

## Запуск

```bash
kotlinc src/Main.kt -include-runtime -d main.jar
java -jar main.jar
```
