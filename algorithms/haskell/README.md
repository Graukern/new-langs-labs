# Раскрытие вложенных повторов команд на Haskell

Программа принимает строку из команд `F`, `L` и `R`. Запись `N[...]`
повторяет содержимое скобок положительное целое число раз. Внутренние блоки
разбираются рекурсивно. Результат печатается в консоль.

## Запуск

```bash
runghc src/main.hs '2[F3[LR]]'
```

Результат — `FLRLRLRFLRLRLR`.
